# Personal Academic Website

This is a personal academic website built with HTML, CSS, and JavaScript, designed to be hosted on GitHub Pages.

## Features

- **Responsive Design**: Mobile-friendly layout that works on all devices
- **Modern UI**: Clean, professional design suitable for academic use
- **Navigation**: Easy-to-use header navigation with all major sections
- **Sections Included**:
  - Home/Welcome page with introduction and latest news
  - Research
  - People (research group, collaborators)
  - Publications
  - Teaching
  - Services
  - Awards & Recognition

## File Structure

```
├── index.html          # Home page
├── research.html       # Research page
├── people.html         # People page
├── publications.html   # Publications page
├── teaching.html       # Teaching page
├── services.html       # Services page
├── awards.html         # Awards page
├── styles.css          # Main stylesheet
├── script.js           # JavaScript functionality
├── images/             # Images folder (profile photo, etc.)
└── README.md           # This file
```

## Customization

1. **Personal Information**: Update the following in `index.html`:
   - Your name, title, affiliation, email
   - Research interests
   - About section content
   - Latest news items

2. **Profile Photo**: Add your photo as `images/profile.jpg`

3. **Content**: Update each page with your specific content:
   - Research projects and methods
   - Publications list
   - Teaching experience
   - Awards and recognition
   - Service activities

4. **Styling**: Modify `styles.css` to change colors, fonts, or layout

5. **Contact Links**: Update footer links with your actual social media profiles

## GitHub Pages Setup

1. Push your code to the GitHub repository
2. Go to repository Settings > Pages
3. Select source as "Deploy from a branch"
4. Choose "main" branch and "/ (root)" folder
5. Your site will be available at `https://yourusername.github.io`
